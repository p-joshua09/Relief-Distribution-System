# ReliefLink front-end prototype

An interactive, responsive front-end concept for the DSWD Relief Goods Distribution System. It reflects the supplied use cases: biometric capture, beneficiary and household records, eligibility checks, claim history, and goods release.

## Open it

Open `index.html` in a modern browser. The prototype uses Bootstrap from its CDN and requires no server, database, or Node/Express setup.

## Included interactions

- Toggle between face and fingerprint capture.
- Capture a biometric sample and simulate an unmatched beneficiary result.
- Create a beneficiary/household record with location, age, income, and household relationships.
- Save the draft, assess eligibility, prepare a relief package, and record the release.

This is presentation-layer only. All people, status values, and matching outcomes are sample UI data; actual biometric processing and claim enforcement belong in the secured backend.
