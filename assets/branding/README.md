# Agency artwork

Downloaded on 4 October 2026 from official DSWD websites. Files are stored unchanged; display them at their original aspect ratios with space around the marks.

| Local file | Official source | Use |
| --- | --- | --- |

| `bagong-pilipinas-logo.png` | [Bagong Pilipinas artwork](https://caraga-iris.dswd.gov.ph/static/staticfiles/image/Bagong_Pilipinas_logo.png), linked by the same agency site | Header and receipt |

Interface accents use blue `#2e3192`, red `#ee1c25`, and yellow `#fef200`, as specified in the [DSWD Field Office I 2024 envelope procurement artwork requirements](https://fo1.dswd.gov.ph/wp-content/uploads/2024/09/24-DSWDFO1-08-SPPMO-Envelopes-min.pdf). Navy and pale blue surfaces are interface supporting colors. Status colors retain their separate operational meanings.

The footer phrase “Maagap at Mapagkalingang Serbisyo” appears in the [DSWD NCR agency values](https://ncr.dswd.gov.ph/about-us/visionmissionvalues/).

This repository remains a front-end prototype using fictional sample records. The artwork does not imply deployment or approval by the agency.
